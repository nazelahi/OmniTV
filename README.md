# OmniStream TV

Modern responsive Live TV player and playlist manager with instant channel switching, EPG schedule guide, and HLS streaming.

## Setup

```bash
bun install
cp .env.example .env   # configure GEMINI_API_KEY if needed
```

## Run (development)

```bash
bun run dev
```

Server runs on http://localhost:3000.

## Build

```bash
bun run build
bun run start   # production
```

## Test

```bash
bun run test
```

## Lint

```bash
bun run lint
```
